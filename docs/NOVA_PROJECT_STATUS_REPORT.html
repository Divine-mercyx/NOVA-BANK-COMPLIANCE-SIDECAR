4. Step-by-Step Flows

Flow A — VPN laptop setup

1. Install Docker, Git, Node 18+, Python 3.11+
2. Connect bank VPN
3. git clone https://github.com/Divine-mercyx/NOVA-BANK-COMPLIANCE-SIDECAR.git
4. docker compose up -d
5. cp backend/.env.example backend/.env
   Set: FINACLE_MODE=oracle, FINACLE_ORACLE_SOURCE=htd
   FINACLE_ORACLE_DSN=10.0.240.180:1625/NOVAPRD (or :1521)
   FINACLE_ORACLE_USER=customer, FINACLE_ORACLE_PASSWORD=***
6. Terminal 1: ./scripts/start-backend.sh
7. Terminal 2: ./scripts/start-frontend.sh
8. Browser → http://localhost:5173 → login → OTP from backend terminal

Flow B — ETL (Finacle → staging)

TBAADM.HTD + TBAADM.GAM
    → Extract (Oracle query)
    → Pair D/C legs by TRAN_ID + amount
    → Transform (validate, PEP/CTR/FTR/STR flags)
    → Load to PostgreSQL staging
    → Dashboard / Data Quality / Extraction pages

Trigger: Dashboard → "Run extraction" (analyst+)
     OR: POST /api/v1/etl/run
     OR: Scheduled cron (ETL_SCHEDULE_ENABLED=true)
     OR: Middleware POST /api/v1/ingest/transactions

Flow C — Regulatory reporting

Staging (flagged txns)
    → Reports → Generate CTR/FTR/PEP/STR
    → XML + CSV saved (DRAFT)
    → Approver reviews → Approve
    → Submit (audit logged — not yet real NFIU portal)
    → Audit Trail

Flow D — Screening

Path 1: Simulate flags (demo) → Alert queue → Review
Path 2: POST /api/v1/screening/check (middleware) → clear | review → alert
Path 3: Analyst approve/reject; Approver escalate

Flow E — Production completion

Phase 1  Live Oracle ETL validated on VPN laptop
Phase 2  30-day parallel UAT run
Phase 3  goAML XSD reports pass validation
Phase 4  NFIU sandbox test submission
Phase 5  Real sanctions/watchlist for M2
Phase 6  Middleware integrated (Module 4)
Phase 7  Prod hosting, OTP email/SMS, monitoring
Phase 8  Compliance + IT sign-off
Phase 9  Go-live
